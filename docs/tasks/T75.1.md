## T75.1: Rank declared edit/test paths in optional orientation

### Objective
Generic failure evidence no longer selects unrelated fixtures ahead of the declared task.

### Scope
Modify `lib/kazi/loop.ex`, `lib/kazi/context.ex`,
`lib/kazi/context/repo_map_source.ex`, `test/kazi/context_test.exs`, and
`test/kazi/loop/orientation_prefix_test.exs`. Out of scope: write permissions,
new retrieval systems, paid ranking models, tier/default changes.

### Acceptance criteria
Create a temporary repo with declared source and test paths plus an unrelated
deployment fixture containing unique sentinels. Use generic failure evidence that
names none of them. At a bounded allowance sufficient for the relevant pair,
capture the actual prompt and assert both relevant paths present and unrelated
fixture absent. Run through both graph-source and fallback injection seams.
Repeat with empty scope, missing path, and identical input; fallback is bounded
and deterministic. Keep read paths distinct from write permission.
Genuine red: remove explicit path ranking and require the original fixture
selection test to fail before restoring the implementation.
