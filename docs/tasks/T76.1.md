## T76.1: Select one complete usage source and conserve tokens

### Objective
The Claude adapter reports complete model usage without counting overlapping envelopes twice.

### Scope
Modify `lib/kazi/harness/profiles/claude.ex`, `lib/kazi/harness/usage.ex`,
`test/kazi/harness/claude_adapter_test.exs`, `test/kazi/harness/usage_test.exs`.
Out of scope: real API calls, receipt ingestion, price tables, budget policy changes.

### Acceptance criteria
Build synthetic envelopes from small explicit numeric fields; one complete
`modelUsage` sums to 1352533 while top-level `usage` sums to 1277629.
Select the complete per-model shape and report 1352533, never their sum.
Add two-model, top-level-only, malformed, partial, absent, and zero-valued cases.
Malformed/partial per-model data uses a valid whole top-level fallback with its
source/fidelity recorded; when neither shape is valid report unknown, not zero.
Conservation requires fresh input + cache read + cache write + output = total;
reasoning remains a subset of output and is never added again.
Genuine red: restore top-level-only source selection and observe the exact total
assertion fail before restoring the fix. Retain legacy valid top-level behavior.

`mix format --check-formatted`
