# E75 -- Optional orientation tuning (deferred)

Status: deferred, 2026-10-01. No executable task queue is retained here.

The idea is to prioritize declared edit/test paths within optional orientation
and measure its size without truncating the mandatory task contract. It is not
a prerequisite for E74/E76/E78/E79/E80 delivery or the completed E77 evaluation.

Revisit only if a measured integration failure shows that optional orientation
is limiting accepted, landed changes. Any renewed work needs a fresh scope and
acceptance contract against the current code; the old T75.1–T75.3 decomposition
is not an assignment. Existing context mechanisms remain supported.
