# E72 -- Per-directory AGENTS.md projection and `write_paths` as declared scope (ADR-0086)

Back-link: [docs/plan.md](../plan.md) (master index). Sibling epics: [plans/](.)

fidelity: executable

Implements ADR-0086. A goal's `[scope].write_paths` (fallback `paths`) is
its declared scope; a pure render `render(goal.toml, scope root, observe
result)` produces a per-scope-root `AGENTS.md` node that is never committed,
delivered either as an ignored file for the harness walk-up (interactive) or
embedded by a dispatcher in a lane's existing prompt channel. Tamper
protection is freshness (re-render and byte-compare; sha in a lane contract)
plus auto-added `forbidden_paths` (ADR-0085), never sealing a derived file.
Nested scope roots are refused in v1; unscoped goals render nothing; the
generator never touches a hand-written file.

Code anchors verified on origin/main at write time (2026-09-05):
`Kazi.Scope` (lib/kazi/scope.ex) holds `paths`, `write_paths`, `deny`;
`Kazi.CollateralReport` consumes `write_paths`; ADR-0085's `forbidden_paths`
guard is the enforcement primitive decision 5(c) reuses; `kazi plan render`
(ADR-0056/0082) is the render entry point `--tree` extends; the ADR-0065 §5
worktree indirection is what `--tree` must route through. `Kazi.Fleet`
(lib/kazi/fleet.ex:350-370) already prefers `write_paths` over `paths` for
ADR-0065 §3 overlap inference and tests overlap by string prefix -- T72.1
fixes the prefix test to globs and leaves the unscoped-goal rule alone.

Out of scope here: the hq dispatcher change (lane.sh, the cloud canary
dispatcher) that embeds the rendered node and records its sha in the lane
contract -- dispatcher-class, tracked and reviewed in that repo. `kazi adopt`
proposing scope from directory ownership -- its own ADR.

Acceptance: every task's `acc:` green; docs land with the code (ADR-0034);
`kazi plan render --tree` and `kazi apply --cwd` documented in `kazi help`,
README/`docs/`, and `AUTHORING.md`; the symlink walk-up claim in ADR-0086
decision 6 is backed by a test, not prose.

  amendment.
